# Task Tracker v2 (Full Application) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the v1 single-page tracker into a multi-page application with a collapsible sidebar,
light/dark theme, Dashboard, upgraded Tasks, Team members, and Roles & access, using shadcn/ui and the
KAIRO visual language, without changing the v1 API contract.

**Architecture:** The same npm workspaces. `shared/` gains member, assignee and dashboard schemas.
`server/` gains a Member model and the `/api/members`, `/api/tasks/:id/assignee` and
`/api/dashboard/summary` endpoints, plus a seed module. `client/` moves to React Router + TanStack
Query + shadcn/ui, with feature folders.

**Tech Stack:** Express 5, Mongoose 9, Zod 4, Vitest 5 · React 19, Vite 8, Tailwind 4, shadcn/ui 4
(Radix base), react-router 7.18, @tanstack/react-query 5, @fontsource-variable/geist, lucide-react.

**Spec:** [docs/superpowers/specs/2026-11-20-full-app-design.md](../specs/2026-11-20-full-app-design.md)
(read it in full; it carries the visual tokens, page contents and settled calls).

## Global Constraints

- Branch `feature/full-app`. Never commit to `main`. Never push.
- **The v1 contract is frozen:** `GET/POST/PATCH/DELETE /api/tasks` keep their v1 behavior. PATCH
  `/api/tasks/:id` still accepts only `status`/`priority`. All 51 v1 tests must pass **unmodified**.
- TypeScript strict, no `any`, no `@ts-ignore`, no escaping casts. typescript-eslint `recommendedTypeChecked` stays.
- Every request and response shape is defined once in `shared/` (Zod), and types come from `z.infer`.
- Use `react-router@^7.18` (v8 requires Node ≥ 22.22, which conflicts with engines `^22.13.0 || >=24.0.0`).
- Visual tokens are exactly the spec's "Visual system" table (KAIRO values) for light and dark.
  Use the Geist font via `@fontsource-variable/geist`.
- No dead UI (no bell, no settings page, no user menu). No emoji in the product.
- Copy rules: plain and specific. Don't copy KAIRO's name, logo or wording.
- Add dependencies by editing package.json and doing a clean reinstall. Keep
  `node_modules/.cache/mongodb-memory-server` by moving it aside and back.
- A project `.npmrc` must force `registry=https://registry.npmjs.org/`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Assigning to a deactivated member.** Selecting or POSTing an inactive member → 400 on
   `assigneeId`, and the UI never offers inactive members in pickers. Tests: Task 4.
2. **Duplicate email with different case or whitespace** (`" Arun@Team.dev "` vs `arun@team.dev`)
   → 409 on `email`, not a second member. Tests: Task 2 (normalization) and Task 3 (409).
3. **Demoting or deactivating the last active admin** → 400 and nothing changes. When zero admins
   exist, edits are allowed. Tests: Task 3.
4. **Theme and sidebar state across reloads.** Dark mode doesn't flash light on load, and a
   collapsed sidebar stays collapsed. Checked in Task 12's browser check.
5. **Re-opening a done task** clears `completedAt`, so "Done this week" doesn't count it. Test: Task 4.
